# 📊 Intelligent Business Automation Assistant

An AI-powered business analytics platform that allows users to upload structured business datasets (CSV / Excel), automatically analyze them, generate KPIs, detect patterns, and produce business insights through an interactive dashboard.

---

# 🚀 Project Overview

Organizations often collect operational data but spend significant time manually analyzing spreadsheets.

This system automates that workflow by:

- Accepting uploaded business datasets
- Cleaning and validating raw data
- Detecting schema dynamically
- Generating business KPIs
- Creating interactive visualizations
- Producing AI-powered business recommendations
- Exporting processed reports

# ⚙ Installation

Clone repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into project:

```bash
cd intelligent-business-automation-assistant
```

Create virtual environment:

```bash
python -m venv venv
```

Activate environment:

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run application:

```bash
streamlit run app/app.py
```
